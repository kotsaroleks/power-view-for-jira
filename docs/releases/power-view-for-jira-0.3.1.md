# Power View for Jira 0.3.1 — встановлення

1. Завантажте й розпакуйте `power-view-for-jira-0.3.1.zip` у постійну папку.
2. У Chrome відкрийте `chrome://extensions` та увімкніть «Режим розробника».
3. Натисніть «Завантажити розпаковане розширення» та виберіть папку, яка містить
   `manifest.json`.
4. Відкрийте свою Jira, натисніть іконку Power View та «Open Power View». Якщо Chrome
   запитає доступ до поточного Jira-сайту — надайте його.
5. Для Day Off один раз дозвольте «Allow GitHub storage access», якщо з'явиться такий
   запит. Особистий GitHub/Google-вхід і персональний токен не потрібні.

У Settings → App sections кожен розділ вмикається й вимикається тумблером. Початково
Reports та Estimation board вимкнені; Timesheet, Gantt і Status chart увімкнені. Вимкнені
розділи приховані в навігації та Workspace. Налаштування зберігаються на цьому
встановленні.

Для оновлення наявного встановлення замініть файли в його папці новою версією та натисніть
«Перезавантажити» на картці Power View у `chrome://extensions`. Не видаляйте папку
розширення після встановлення. Встановлювати застосунок у Jira не потрібно.
