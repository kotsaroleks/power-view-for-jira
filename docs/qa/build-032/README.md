# Перевірка UX збірки 032

Production web bundle, ізольований Google Chrome, Jira/GitHub fixtures із TEST DATA. Ці
скриншоти не містять результатів запису в реальну Jira.

- [Дата за Jira-профілем](jira-profile-date.png): перехід на America/Los_Angeles після
  повторного відкриття; запис 2 листопада 14:00 −08:00 знаходиться в колонці 2 листопада.
  Видиме неблокуюче попередження показує відхилення −10h від Kyiv.
- [Попередження на вузькому екрані](time-zone-warning-mobile.png): 390 px, ручний перегляд
  у Europe/Kyiv; попередження про America/Los_Angeles залишається видимим, текст
  переноситься без горизонтального переповнення сторінки.
- [Помилка введення](invalid-entry.png): чернетка збережена, причина й повторне читання
  доступні в комірці, перемикання контексту захищене.
- [Вузьке вікно](timesheet-mobile.png): навігація та Settings доступні без накладання.
- [Місячна норма](monthly-capacity.png): норма за погодженими буднями та Day Off;
  браузерний тест перевіряє 344h для двох тестових людей у жовтні 2026.

Методика, виправлення, перевірки реального worklog і межі валідації:
[звіт 0.3.2](../../releases/power-view-for-jira-0.3.2.md).
