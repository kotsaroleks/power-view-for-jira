# Power View: повна нативна Swift-копія

Уточнення замовника: 20 жовтня 2026 року.

Мета — повна копія наявного Chrome/desktop продукту, написана нативно на Swift. Попередня
обгортка була правильним еталоном продукту: замінити потрібно реалізацію, зберігши дизайн,
структуру, навігацію, тексти, дані, логіку та користувацькі дії. Дошка естимації входить у
цей продукт.

Це не дозвіл спроєктувати новий застосунок із подібними функціями. Наявність екрана з
назвою Gantt, робочих формул або успішної збірки не є виконанням замовлення.

## Джерела істини

- `apps/web/src/app/App.tsx`, `DesktopApp.tsx` — навігація, Workspace, setup/connection.
- `apps/web/src/styles/global.css`, `packages/ui/src/tokens.css` — дизайн, розміри,
  кольори, типографіка.
- `apps/web/src/app/SetupPanel.tsx`, `workspace/BoardConfigurationTransfer.tsx`,
  `packages/storage/src/settings-store.ts` — setup, поля, збереження й реальні portable
  settings.
- `apps/web/src/app/gantt-v2/` та відповідні `packages/domain/src/` — вигляд і всі
  взаємодії Gantt, каскади, зовнішні зміни, клавіатура, constraints.
- `apps/web/src/app/status/` — Status chart.
- `apps/web/src/app/reports/`, `reporting/` — Board Health, builder, результати, історія,
  PDF та фільтри.
- `apps/web/src/app/estimation/` — п'ять етапів, всі поля, gates/invalidation,
  імпорт/експорт і збереження дошки.

## Приймання

Для кожного екрана й дії потрібні:

1. Однакові контрольні дані у Chrome й Swift.
2. Порівняння екранів при однаковому розмірі вікна: структура, відступи, кольори,
   типографіка, стани й розміщення елементів.
3. Ті самі дії та результати: переходи, розрахунки, фільтри, помилки, збереження, повторне
   відкриття, артефакти експорту.
4. Для Jira — правильні інстанція/борд/поля/особа, читання після запису, часткові помилки
   й скасування. Cloud/Data Center не вилучаються мовчки.
5. Для міграції — справжній файл, отриманий кнопкою Chrome Export, з перевіркою зворотного
   імпорту оригінальним importer. Налаштування й приватні дані різних бордів не
   змішуються.
6. Незалежна перевірка. Компіляція й unit fixtures — додаткові докази, не заміна UI та
   наскрізного приймання.

Системні рамка вікна, файлові діалоги та введення desktop credentials є платформними
деталями. Вони не виправдовують зміну дизайну екранів або логіки продукту. Інші
відмінності потребують погодження замовника.

## Відкинута реалізація

Попередній release-first Swift UI із sidebar, власними ролями, формою StoryEditor та іншою
дошкою відкинуто. Його не слід доповнювати й видавати за копію Chrome. Попередні ТЗ та
аудити залишаються історією, а не чинною специфікацією продукту.

Жоден пункт не вважається виконаним лише тому, що для нього існує Swift-файл. Актуальні
невідповідності фіксуються в `native-macos-copy-gap-audit.md` і перевіряються після
виправлення. Поки вони не закриті, результат не є завершеним переносом.
